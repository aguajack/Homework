# Sorting Project Report

## 1. Project Goal

The goal of this project is to implement and compare four sorting algorithms:

1. Insertion Sort
2. Quick Sort with median-of-three pivot selection
3. Iterative Merge Sort
4. Heap Sort

After measuring their runtimes, a Composite Sort function is designed to select a suitable sorting algorithm based on the input size.

## 4. Sorting Algorithms

## 4.1 Insertion Sort

Insertion Sort repeatedly inserts each element into its correct position.

Worst-case time complexity:

```text
O(n^2)
```

Worst-case input:

```text
Reverse-sorted array
```

---

## 4.2 Quick Sort

Quick Sort is implemented with median-of-three pivot selection.

Average-case time complexity:

```text
O(n log n)
```

Worst-case time complexity:

```text
O(n^2)
```

---

## 4.3 Iterative Merge Sort

Merge Sort is implemented using the iterative method.

Time complexity:

```text
O(n log n)
```

---

## 4.4 Heap Sort

Heap Sort builds a max heap and repeatedly extracts the maximum element.

Time complexity:

```text
O(n log n)
```

Observation:


## 11. Composite Sort Design

The Composite Sort function can use one of the following strategies depending on the criterion:

```text
Worst-case criterion:
n <= 32: use Insertion Sort
n > 32:  use Merge Sort

Average-case criterion:
n <= 32: use Insertion Sort
n > 32:  use Quick Sort
```

Reason:

```text
For the tested input sizes, Merge Sort was best under the worst-case criterion, while Quick Sort was best under the average-case criterion. Insertion Sort is kept for very small arrays because it has low overhead.
```

## 12. Conclusion

In this project, four sorting algorithms were implemented and tested.

Final conclusion:

```text
The experimental results show that the best sorting algorithm depends on the criterion. Merge Sort is recommended for the worst-case criterion, while Quick Sort is recommended for the average-case criterion. Insertion Sort is useful only for small input sizes.
```

Possible conclusion format:

- Insertion Sort is useful for small input sizes.
- Quick Sort is efficient in average cases.
- Merge Sort has stable performance.
- Heap Sort has stable O(n log n) performance.
- Composite Sort can improve runtime by selecting algorithms according to input size.
