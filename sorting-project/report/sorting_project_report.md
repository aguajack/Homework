# Sorting Project Report

## 1. Project Goal

The goal of this project is to implement and compare four sorting algorithms:

1. Insertion Sort
2. Quick Sort with median-of-three pivot selection
3. Iterative Merge Sort
4. Heap Sort

After measuring their runtimes, a Composite Sort function is designed to select a suitable sorting algorithm based on the input size.

## 4. Sorting Algorithms

## 4.1 Insertion Sort

Insertion Sort repeatedly inserts each element into its correct position.

Worst-case time complexity:

```text
O(n^2)
```

Worst-case input:

```text
Reverse-sorted array
```

---

## 4.2 Quick Sort

Quick Sort is implemented with median-of-three pivot selection.

Average-case time complexity:

```text
O(n log n)
```

Worst-case time complexity:

```text
O(n^2)
```

---

## 4.3 Iterative Merge Sort

Merge Sort is implemented using the iterative method.

Time complexity:

```text
O(n log n)
```

---

## 4.4 Heap Sort

Heap Sort builds a max heap and repeatedly extracts the maximum element.

Time complexity:

```text
O(n log n)
```
