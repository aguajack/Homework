# Data Folder

This folder stores runtime measurement results.

## Files

| File | Description |
|---|---|
| `worst_case_results.csv` | Runtime results for worst-case experiments |
| `average_case_results.csv` | Runtime results for average-case experiments |

## CSV Format

```csv
n,insertion_sort,quick_sort,merge_sort,heap_sort,composite_sort
500,,,,,
1000,,,,,
2000,,,,,
3000,,,,,
4000,,,,,
5000,,,,,
```

Runtime unit:

```text
milliseconds
```
